# L3 Lateral Earth Pressure (67p, CIE3032) — 노트 전반부 pp.1–12 (쪽=PDF쪽, 슬라이드 번호=PDF쪽−1 이후 구간 있음; 각 시트 두 쪽)
- p2 K=σ'h/σ'o (수평/연직 유효응력비). 정지(static) K=Ko=σ'h/σ'o
- p3 정지토압: 마찰 없는 벽 AB 옆 흙요소, 연직 유효 σ'o, 수평 σ'h=Ko σ'o. 능동: 벽이 흙에서 멀어져(ΔLa) K=Ka=σ'a/σ'o. 수동: 벽이 흙 쪽으로 밀려(ΔLp) K=Kp=σ'p/σ'o. 파괴 기준 τf=c'+σ'tanφ' [그림 p3~4: 정지/능동/수동 모식도 크롭 후보]
- p4 벽 변위–토압 곡선: 벽 기울임 ΔLa/H(능동), ΔLp/H(수동) 에서 토압이 능동 최소 ~ 수동 최대로 수렴. **Table 13.1 ΔLa/H, ΔLp/H**: 느슨한 모래 0.001–0.002 / 0.01; 조밀한 모래 0.0005–0.001 / 0.005; 연약 점토 0.02 / 0.04; 단단한 점토 0.01 / 0.02. (능동에 필요한 변위가 수동보다 훨씬 작다) 우측 그림: 수동은 곡선면, 능동은 평면 파괴면 [그림 p4 크롭 후보]
- p5 정지토압(마찰없는 벽): σ'o=γz, σ'h=Koγz. **Jaky(1944)**: Ko=1−sinφ' (NC) ; 과압밀: Ko=(1−sinφ')(OCR)^sinφ'
- p6 부분 수침 흙: 정지토압 = 유효수평응력 σ'h(Ko×σ'o) + 간극수압 u. 지하수위 위 층 H1(γ), 아래 H2(γsat, γ'=γsat−γw). 하단 σ'h = Ko(γH1+γ'H2), 수압 γwH2 [그림 p6 크롭 후보]
- p7~9 **예제 13.1**: 높이 4.5 m 벽, 항복 구속(정지상태). 모래 c'=0, φ'=35°, 지하수위 위 3 m γ=15.7, 아래 1.5 m γsat=19.2 kN/m³, OCR=1.5. 구하는 것: 단위길이당 횡력 Po와 합력 위치(벽 바닥 기준)
  - Ko=(1−sin35°)(1.5)^sin35° = 0.538 (재계산: 1−0.5736=0.4264; 1.5^0.5736=e^(0.5736×0.4055)=e^0.2326=1.262; 0.4264×1.262=0.538 ✓)
  - z=3: σ'o=3×15.7=47.1; σ'h=0.538×47.1=25.34 kPa; u=0
  - z=4.5: σ'o=47.1+1.5(19.2−9.81)=61.19; σ'h=0.538×61.19=39.92; u=1.5×9.81=14.72 kPa
  - Po=면적1+2+3+4=½·3·25.34 + 1.5·25.34 + ½·1.5·(39.92−25.34=14.58) + ½·1.5·14.72 = 38.01+38.01+10.94+11.04=98 kN/m ✓
  - 합력 위치 z̄(바닥 C 기준)=Σ모멘트/Po: 38.01(1.5+3/3)+38.01(1.5/2)+10.94(1.5/3)+11.04(1.5/3) = 95.03+28.51+5.47+5.52=134.5 → /98 = **1.37 m**. 교안은 1.76 m — **교안 오류(식의 숫자와 결과 불일치). 1.37 m 채택, CAUTION**
