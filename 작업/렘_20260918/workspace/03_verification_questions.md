## 질문

### V-001
분류: 결론 영향
대상: `02` §B Q3 / 근거 ID S09
지금 조사에 적힌 것: "숲의 심문 장면 말미에는 렘이 놀라는 가운데 다른 공격으로 스바루의 목이 손상된다. 이 장면의 모든 타격과 최후의 일격을 렘 한 사람에게 귀속시키면 안 된다."
무엇이 의심스러운가: "렘이 스바루를 살해했다가 신뢰를 쌓아간다"는 매력 서사(Blueprint 질문3, 핵심 프레이밍)의 전제 자체가 "렘이 죽였다"는 사실에 의존한다. 최후의 일격이 렘이 아닌 다른 존재의 것이라면 이 프레이밍을 다시 짜야 한다.
유리가 내야 할 것: S09 본문에서 최후의 일격을 가한 주체가 누구로 서술되는지 원문 구절을 직접 인용해 특정.

### V-002
분류: 사실·추론 혼동 (E-031 Character Model 핵심 검증 대상)
대상: `02` §B Q1 외형 표 "뿔" 행 / 근거 ID S07·S08
지금 조사에 적힌 것: "렘의 뿔 위치는 이마 부근"
무엇이 의심스러운가: 이 항목만 근거 위치(L 번호)가 다른 세부와 달리 특정되지 않았다. "이마 부근"이 원문 표현인지 오니 설정 일반론에서 끌어온 추론인지 불명확하다.
유리가 내야 할 것: S07 또는 S08 본문에서 뿔 위치를 "이마"로 명시하는 정확한 원문 구절과 L 번호. 없으면 [미확인]으로 재분류.

### V-003
분류: 근거 불일치
대상: `02` §B Q1 외형 표 "머리" 행 / 근거 ID S06

무엇이 의심스러운가: 인용된 단편 구절만으로는 "水色"(물빛)이 문법적으로 무엇을 수식하는지(머리카락 전체인지, 앞머리 한 가닥인지, 다른 장식인지) 불명확하다. 외형 가이드라인의 핵심 근거라 대상어가 정확해야 한다.
유리가 내야 할 것: S06 L341-350 부근에서 "水色"이 수식하는 명사를 포함한 전체 문장 원문 인용.
