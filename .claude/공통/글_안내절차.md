# 글 유형 — 안내·절차

## 좋은 글의 기준
대상 독자가 자신의 조건에 맞는 경로를 골라 작업을 끝내고, 완료 여부를 확인할 수 있다. 친절한 설명보다 실행에 필요한 정보의 정확성과 위치가 우선이다.

## 기획·조사 재료
대상·자격·준비물, 시작 조건, 실제 순서, 선택 분기, 예외·실패 시 조치, 완료 확인을 확보한다. 비용·처리 시간·버전·법적 조건은 해당 시점의 공식 자료로 확인한다.

## 집필
- 처음에 대상과 완료할 일을 밝히고, 실행 전 필요한 준비를 둔다.
- 순서가 있는 행동에는 번호를 쓰고, 각 단계는 할 일을 나타내는 동사로 시작한다. 필요한 설명·주의는 그 행동 옆에 둔다.
- 조건이 다르면 분기점을 표시한다. 한 번에 필요한 정보만 제시하고 배경 설명은 실행을 방해하지 않게 배치한다.
- 마지막에는 완료 상태와 다음 절차를 안내한다. 핵심 순서·예외가 근거에 없으면 그럴듯한 절차로 메우지 않고 작업 보고에 남긴다.

## 완료 기준
준비 → 실행 → 분기 → 완료 확인이 끊기지 않는가? 독자가 같은 행동을 반복하거나 필수 단계를 건너뛸 여지가 없는가? 실제 행동 지시와 확인 조건을 검수 말투로 오인해 삭제하지 않았는가?
