# 지반공학 이론정리본

이 자료는 지반공학 교안 다섯 편(토질역학 복습, 전단강도, 현장시험, 토압, 사면안정)을 시험 직전에 한 번에 훑도록 압축한 정리본이다. 각 장은 한 줄 요약, 핵심 개념과 공식, 교안에서 잘라 온 그림, 시험 포인트, 필기칸 순서로 이어진다. 풀이 과정이 필요한 예제는 별도의 연습문제정리본에 단계별로 풀어 두었다.

공식 앞에는 용도를 알려 주는 표지를 붙였다. **[개념]** 은 뜻과 이유, **[공식]** 은 외워서 쓰는 식, **[암기]** 는 값이나 목록, **[패턴]** 은 문제에서 반복되는 풀이 틀, **[필수]** 는 빠뜨리면 점수가 깎이는 조건, **[스킬]** 은 계산을 줄이는 요령이다.

::: summary 전체 한눈에 보기
- 흙의 상태는 삼상(고체·물·공기)의 부피와 무게 관계로 나타내고, 세립토의 거동은 아터버그 한계로 가른다.
- 전단강도는 모어-쿨롱식 `τf = c + σ'·tanφ'` 로 쓰며, 응력 상태는 모어 원으로 읽는다.
- 현장시험은 SPT(N값), CPT(qc), 베인시험(Su), 공내재하시험, 딜라토미터, 탄성파로 나뉘고 각각 얻는 값과 보정식이 다르다.
- 토압은 정지(K0), 능동(Ka), 수동(Kp) 세 상태로 나누고, Rankine은 응력 상태로, Coulomb은 힘의 평형으로 구한다.
- 사면안정은 안전율 `FS = τf/τd` 로 판정하며 무한사면, 평면파괴(Culmann), 원호파괴(절편법, Bishop)로 이어진다.
:::

# 0. 토질역학 복습

::: summary 한 줄 요약
흙은 고체, 물, 공기의 세 상으로 이루어지고, 나머지 상태량은 `Vs = 1` 로 놓고 그린 삼상도에서 나온다.
:::

## 0-1. 삼상 관계

**[개념]** 흙 덩어리의 전체 부피 `V = Vs + Vw + Va = Vs + Vv`, 전체 무게 `W = Ws + Ww` 이다. 공기의 무게는 0으로 둔다.[S01]

![삼상 모식도와 삼상도. 부피 Vs, Vw, Va와 무게 Ws, Ww의 관계를 나타낸다](../references/fig/L0_05.png "CIE3032 Lec 00 교안 PDF p.5"){wide}

**[공식]** 기본 지표는 다음과 같다.[S01]

| 지표 | 식 | 범위·비고 |
| --- | --- | --- |
| 간극비 e | `Vv/Vs` | 대부분의 흙 0.4~1.0 |
| 간극률 n | `Vv/V` | 0~1, `n = e/(1+e)` |
| 포화도 S | `Vw/Vv × 100%` | 0(건조)~100%(포화) |
| 함수비 w | `Ww/Ws × 100%` | |
| 비중 Gs | `Ws/(Vs·γw)` | 2.65~2.75 |

**[공식]** 단위중량은 세 가지를 구분한다. 물의 단위중량은 `γw = 9.81 kN/m³` 이다.[S01]

- 습윤(전체): `γ = Gs·γw·(1+w)/(1+e)`, 범위 15.7~20.4 kN/m³
- 건조: `γd = Gs·γw/(1+e) = γ/(1+w)`
- 포화(S = 100%): `γsat = W/V`
- 크기 순서: `γd ≤ γ ≤ γsat`

**[공식]** 상대밀도는 `Dr = (emax − e)/(emax − emin) × 100%` 이다. 가장 느슨할 때 e가 emax, 가장 조밀할 때 emin이다.[S01]

**[스킬]** 삼상 문제는 `Vs = 1` 로 놓고 삼상도를 그린 뒤, 주어진 값(e, w, Gs 중 둘 등)으로 나머지 칸을 채우면 대부분 한 줄씩 풀린다. 이 요령은 정리본 작성자의 제안이며 교안의 지시가 아니다.

## 0-2. 입도와 분류

**[암기]** 입경 구분은 실트·점토 0.075 mm 미만, 모래 0.075~4.75 mm, 자갈 4.75~75 mm, 왕자갈(cobble) 75~300 mm, 호박돌(boulder) 300 mm 초과이다. 0.075 mm(#200체)보다 가는 흙을 세립토라 한다.[S01]

**[공식]** 균등계수 `Cu = D60/D10`, 곡률계수 `Cc = D30²/(D60·D10)` 이다. D10은 유효입경, D50은 중앙값이다.[S01]

## 0-3. 아터버그 한계와 USCS

**[개념]** 함수비가 커지면 흙은 고체, 반고체, 소성, 액성 상태로 바뀌고, 경계 함수비를 수축한계(SL), 소성한계(PL), 액성한계(LL)라 한다.[S01]

![아터버그 한계. 부피와 함수비 그래프, 소성지수와 액성지수 식](../references/fig/L0_13.png "CIE3032 Lec 00 교안 PDF p.13"){wide}

**[공식]** 소성지수 `PI = LL − PL`, 액성지수 `LI = (w − PL)/PI` 이다. w는 현장 함수비다.[S01]

**[암기]** USCS 기호는 첫 글자 G(자갈)·S(모래)·C(점토)·M(실트)·O(유기질), 둘째 글자 W(양입도)·P(빈입도)·M·C 또는 H(고소성)·L(저소성)이다. 소성도에서 A선은 `Ip = 0.73(wLL − 20)`, U선은 `Ip = 0.9(wLL − 8)`, 고소성과 저소성의 경계는 LL = 50이다.[S01]

## 0-4. 압밀 용어

**[개념]** 선행압밀하중 `σ'c` 는 카사그란데 방법으로 구한다. `σ'o = σ'c` 이면 정규압밀(NC), `σ'o < σ'c` 이면 과압밀(OC)이며 `OCR = σ'c/σ'o` 이다. 압축지수 Cc는 e-log σ' 재하선의 기울기, 재압축지수 Cs(Cr)는 재하 제거선의 기울기다.[S01]

::: summary 시험 포인트
1. `n = e/(1+e)`, `γd = γ/(1+w)` 처럼 지표 사이의 변환식을 바로 쓸 수 있어야 한다.
2. 단위중량 순서는 `γd ≤ γ ≤ γsat` 이다.
3. `PI = LL − PL`, `LI = (w − PL)/PI` 의 정의를 헷갈리지 않는다.
4. NC는 `σ'o = σ'c`, OC는 `σ'o < σ'c`, 정의는 `OCR = σ'c/σ'o` 이다.
:::

# 1. 전단강도와 모어 원

::: summary 한 줄 요약
응력 상태는 모어 원으로 읽고, 파괴는 그 원이 파괴포락선 `τf = c + σ'·tanφ'` 에 닿는 순간으로 판정한다.
:::

## 1-1. 응력과 부호 규약

**[개념]** 한 점의 응력은 3×3 응력텐서로 나타내고, 전단응력이 0인 세 면의 수직응력이 주응력 `σ1 ≥ σ2 ≥ σ3` (최대, 중간, 최소)이다.[S02]

![응력텐서와 주응력](../references/fig/L1_05.png "CIE3032 Lec 01 교안 PDF p.5"){wide}

**[필수]** 토질역학의 부호 규약은 수직응력은 압축이 +, 전단응력은 시계방향이 +이다.[S02]

**[공식]** 유효응력 `σ' = σ − u`, 전단응력은 간극수압의 영향을 받지 않아 `τ' = τ` 이다. 흙의 강도는 유효응력으로 결정된다.[S02]

## 1-2. 2차원 응력과 모어 원

**[개념]** 연직응력 σv, 수평응력 σh로 이루어진 요소의 모어 원은 두 점 `(σh, −τ)` 와 `(σv, +τ)` 를 지름으로 하는 원이다. `σv > σh` 이면 σv 점이 위쪽(+τ)에 놓인다.[S02]

![2차원 응력 상태와 모어 원, 부호 규약](../references/fig/L1_10.png "CIE3032 Lec 01 교안 PDF p.10"){wide}

**[공식]** 원의 중심과 반지름은 다음과 같다. (σv, σh 가 주응력일 때)

- 중심 `C = (σv + σh)/2`
- 반지름 `R = (σv − σh)/2` 이며 이것이 최대 전단응력 `τmax` 이다
- 편차응력 `σd = σ1 − σ3 = 2R`

전단응력이 함께 작용할 때는 `C = (σv + σh)/2`, `R = √[((σv − σh)/2)² + τ²]`, `σ1 = C + R`, `σ3 = C − R` 이다. 교안 예제(σv = 70, σh = 10, τ = 40 kPa)에서는 `C = 40`, `R = 50`, `σ1 = 90`, `σ3 = −10 kPa` 이 나온다.[S02]

**[패턴]** 모어 원 문제는 대부분 "두 점 → 중심과 반지름 → σ1, σ3 → 주응력면 각도" 순서이며, 임의 면의 응력은 극점법으로 읽는다. 극점법은 기준면 선택, 기준면에 평행선, 극점 찾기, 관심면에 평행선, 응력 읽기의 다섯 단계다.[S02]

![모어 원 예제. σ1 = 90, σ3 = −10 kPa, 각 36.9°와 53.1°](../references/fig/L1_13.png "CIE3032 Lec 01 교안 PDF p.13"){wide}

**[필수]** 모어 원 위의 각도는 실제 면의 각도의 두 배이다. 그림의 36.9°와 53.1°는 원 중심에서 잰 각이다.[S02]

## 1-3. 응력경로

**[개념]** 응력경로는 응력 상태의 변화를 `p-q` 평면에 그린 것이다. 전응력 경로(TSP)와 유효응력 경로(ESP)가 있다. `σ1` 만 늘리고 `σ3` 를 일정하게 두면 기울기 45°의 직선이 된다.[S02]

**[공식]** 램브(Lambe) 좌표는 `p' = (σ1' + σ3')/2`, `q = (σ1' − σ3')/2` 이다. 파괴선(Kf선)은 Mohr-Coulomb 파괴선과 각 α로 연결된다.[S02]

## 1-4. 변형과 탄성 정수

**[공식]** 등방 선형탄성에서 `G = E/[2(1+ν)]`, `K = E/[3(1−2ν)]` 이다. 평균응력 `Δσm = (Δσ1 + Δσ2 + Δσ3)/3` (2차원은 `(Δσ1 + Δσ3)/2`), 체적변형률 `εv = ε1 + ε2 + ε3`, `K = Δσm/εv` 이다.[S02]

## 1-5. 전단강도와 Mohr-Coulomb

**[개념]** 흙의 강도는 곧 전단강도, 즉 내부 저항의 최대값이다. 영향 요인은 흙의 성질(간극비, 입자 특성), 현재 응력 상태, 응력이력(OCR), 파괴까지의 응력경로, 배수조건의 다섯 가지이고, 저항은 마찰과 입자 맞물림에서 나온다.[S02]

**[공식]** 마찰에서 `T = μN`, `μ = tanφ'` 이므로 `τf = σ'f·tanφ'` 이고, 점착력을 더하면 모어-쿨롱 식이 된다.[S02]

- `τf = c + σ'·tanφ'`
- 조립토는 `c = 0` 이라 원점을 지나는 직선이고, 세립토는 c 절편이 있다
- `Su` 는 비배수 전단강도(정체적 전단)이다

**[암기]** 마찰각 대표값(φ'peak / φ'cs, 도)은 다음과 같다.[S02]

| 흙 | φ'peak | φ'cs |
| --- | --- | --- |
| 자갈 | 35~50 | 30~35 |
| 조립+세립 혼합토 | 30~40 | 28~33 |
| 모래 | 32~50 | 27~37 |
| 실트, 실트질 모래 | 27~35 | 24~32 |
| 점토 | 20~30 | 15~30 |

::: note
교안에는 장석이 많은 모래가 높은 값, 석영 모래가 낮은 값을 갖는다는 설명이 붙어 있다. 위 표는 교안의 범위를 그대로 옮긴 것이다.
:::

::: summary 시험 포인트
1. `R = √[((σv−σh)/2)² + τ²]` 로 σ1, σ3 를 구하는 계산이 가장 자주 나온다.
2. 부호 규약(압축 +, 시계방향 전단 +)과 모어 원 각도 2배 관계를 쓴다.
3. 전단강도는 유효응력으로 결정되므로 `σ' = σ − u` 를 먼저 구한다.
4. 조립토는 `c = 0`, 세립토는 c 절편이 있다.
5. 마찰각 표는 `φ'peak > φ'cs` 이고, 점토가 가장 작다.
:::

# 2. 현장시험

::: summary 한 줄 요약
지반조사의 목적은 지층 구성, 기반암 깊이, 설계정수(강도, 강성), 지하수위이며, 시험마다 얻는 값과 쓰는 상관식이 다르다.
:::

## 2-1. 시험 종류 한눈에

**[개념]** 지반조사는 구조물 하부 지층과 그 물리적 특성을 파악하는 과정이며, 목적은 층서 파악, 기반암 깊이, 층별 설계정수, 지하수위의 네 가지다.[S03]

![현장시험 장비 비교. SPT, CPT, DMT, PMT, VST](../references/fig/L2_04.png "CIE3032 Lec 02 교안 PDF p.4"){wide}

| 시험 | 측정값 | 주 용도 |
| --- | --- | --- |
| SPT | N값 | 모래 φ', 점토 연경도 |
| CPT | qc, fs, u | 층 분류, cu, φ' |
| VST | 최대 토크 | 점토 Su |
| PMT | 압력-부피 곡선 | E, G, K0, 한계압력 |
| DMT | A, B 압력 | ID, ED, KD |
| 탄성파 | 전단파 속도 Vs | 소변형 강성 |

## 2-2. SPT (표준관입시험)

**[암기]** ASTM D1586 기준으로 63.5 kg 해머를 76 cm 높이에서 떨어뜨려 스플릿스푼 샘플러(외경 50.8 mm, 길이 76 cm)를 15 cm씩 세 번 관입시킨다. 첫 15 cm는 공저가 교란된 구간이라 버리고, 나머지 두 구간(30 cm)의 타격수 합이 N값이다. 1.5~2 m 간격으로 시행한다.[S03]

**[공식]** 에너지 보정은 `N60 = N·ηH·ηB·ηS·ηR / 60` 이다. 에너지효율은 보통 60%를 기준으로 한다. 이어서 상재압 보정 `(N1)60 = CN·N60` 이고 `CN = √(pa/σ'vo)` 이며 교안은 상한 2를 둔다. `pa ≈ 100 kPa` 이다.[S03]

**[암기]** 보정계수 범위는 다음과 같다.[S03]

| 계수 | 조건 | 값 |
| --- | --- | --- |
| ηH 해머 | 안전해머 | 0.6~0.85 |
| | 도넛해머 | 0.3~0.6 |
| | 자동해머 | 0.85~1.0 |
| ηB 공경 | 65~115 mm | 1.00 |
| | 150 mm | 1.05 |
| | 200 mm | 1.15 |
| ηS 샘플러 | 표준 | 1.0 |
| | 라이너 없음 | 1.1~1.3 |
| ηR 로드 | 10~30 m | 1.0 |
| | 6~10 m | 0.95 |
| | 4~6 m | 0.85 |
| | 3~4 m | 0.75 |

![SPT N값 보정식과 CN 곡선](../references/fig/L2_07.png "CIE3032 Lec 02 교안 PDF p.7"){wide}

**[공식]** 모래의 φ' 상관식은 세 가지다.[S03]

- Wolff(1989): `φ' = 27.1 + 0.3·N60 − 0.00054·N60²`
- Kulhawy & Mayne(1990): `φ' = tan⁻¹[N60/(12.2 + 20.3·(σ'0/pa))]^0.34`
- Hatanaka & Uchida(1996): `φ' = √(20·(N1)60) + 20`

교안의 비교 그래프에서는 Wolff 식이 29~31도대로 작고, 나머지 두 식은 34~38도대로 비슷하게 나타났다.[S03]

**[암기]** 점토의 N60과 연경도는 다음과 같다. qu는 일축압축강도다.[S03]

| N60 | 연경도 | qu (kPa) |
| --- | --- | --- |
| 0~2 | 매우 연약 | 0~25 |
| 2~5 | 연약 | 25~50 |
| 5~10 | 보통 | 50~100 |
| 10~20 | 견고 | 100~200 |
| 20~30 | 매우 견고 | 200~400 |
| 30 초과 | 고결 | 400 초과 |

**[개념]** 면적비 `Ar = (Do² − Di²)/Di² × 100%` 이다. 스플릿스푼은 Ar = 110%라 교란시료이고, Ar이 10% 미만이면 불교란시료로 본다. 2 in 쉘비 튜브의 Ar은 약 13%다.[S03]

::: note
교안은 쉘비 튜브 치수를 cm로 적었다. 계산에서 Ar 13%가 나오는 것은 mm 단위(50.8, 47.63)일 때이므로 표기 오류로 보고 mm로 읽었다.
:::

## 2-3. CPT (콘관입시험)

**[암기]** ASTM D5778 기준으로 선단 60°, 밑면적 1,000 mm²(직경 35.7 mm)의 콘을 2 cm/s로 관입하며 팁저항 qc, 주면마찰 fs, 간극수압 u를 연속 측정한다. 보정 팁저항은 `qt = qc + (1 − an)·u` 이다. 지오폰을 달면 전단파 속도(Vs)도 얻는다(시즈믹 콘).[S03]

**[공식]** 점토의 `cu = (qc − σo)/Nk` 이며 `Nk = 10~20`, 전기식 콘은 15다. 사질토 `φ' = tan⁻¹[0.1 + 0.38·log(qc/σ'o)]`(Kulhawy & Mayne). 탄성계수는 Schmertmann `Es = 2qc`, Trofimenkov는 모래 `3qc`, 점토 `7qc` 이다.[S03]

**[개념]** 흙 분류는 qc와 마찰비 Fr(%)의 도표(Robertson & Campanella 1983), 정규화 도표(Robertson 1990, SBT 1~9)로 한다.[S03]

## 2-4. VST (베인전단시험)

**[암기]** ASTM D2573 기준으로 4날 베인(D = 62.5 mm, H = 130 mm, H/D = 2)을 6°/분으로 돌려 최대 토크 Tmax를 구한다. 이후 10회전 후의 잔류 토크로 재성형 강도를 구한다.[S03]

**[공식]** `Suv = 6·Tmax/(7πD³)` (H/D = 2), 예민비 `St = Suv(peak)/Suv(remolded)` 이다. 설계에 쓰는 값은 보정계수 μ를 곱하여 `Su(design) = μ·Su(VST)`, `μ = 1.7 − 0.54·log(PI)` (Bjerrum 1973)로 구한다. 보정 이유는 전단 방향, 파괴 시간, 교란, 진행성 파괴이다.[S03]

**[공식]** Skempton의 정규압밀 점토 관계는 `Cu(VST)/σ'0 = 0.11 + 0.0037·PI` 이다. 일축압축강도는 `qu = 2Cu` 로 구한다.[S03]

## 2-5. PMT (공내재하시험)

**[개념]** ASTM D4719. 미리 뚫은 공에 프로브(d = 73 mm, L = 440 mm)를 넣고 수압으로 팽창시켜 원통공동팽창 이론으로 해석한다. 얻는 값은 `P0`(lift-off 압력), 탄성계수 E, 전단강도 `τmax`, 한계압력 PL이다.[S03]

![PMT 공식과 압력-부피 곡선(Zone I 재재하, II 의사탄성, III 소성)](../references/fig/L2_31.png "CIE3032 Lec 02 교안 PDF p.31"){wide}

**[공식]** `Es = 2(1 + μs)·V0·Δp/ΔV = 2(1 + μs)·Gs`, `Gs = V0·Δp/ΔV`, `K0 = p0/σ'o` 이다.[S03]

## 2-6. DMT (평판딜라토미터)

**[개념]** 강철 날과 원형 막을 박아 질소가스로 막을 부풀린다. A값은 막이 초기 위치에 닿는 압력, B값은 1.1 mm 변위 시의 압력이다.[S03]

**[공식]** 지수는 다음과 같다.[S03]

- `ID = (p1 − p0)/(p0 − u0)` 재료지수
- `ED = 34.7·(p1 − p0)` 딜라토미터 계수
- `KD = (p0 − u0)/σ'v0` 수평응력지수

**[암기]** ID로 흙을 분류한다. 0.1 미만 연약 점성토·유기질토, 0.1~0.35 점성토, 0.35~0.6 실트질 점토, 0.6~0.9 점토질 실트, 0.9~1.2 모래질 실트, 1.2~1.8 실트질 모래, 3.3 초과 모래다.[S03]

## 2-7. 탄성파 시험

**[개념]** P파는 입자운동이 진행방향과 평행한 압축파, S파는 수직인 전단파이다. 표면파로는 Rayleigh(타원 후진 회전)와 Love(수평 횡운동)가 있다. 지반 강성 평가에는 S파 속도 Vs를 쓴다.[S03]

![다운홀 시험. Vs = ΔR/Δt](../references/fig/L2_41.png "CIE3032 Lec 02 교안 PDF p.41"){wide}

**[공식]** 크로스홀은 `Vs = Δx/Δt`(두 시추공 사이 거리 / 도달 시간차). 다운홀은 `R1² = z1² + x²`, `R2² = z2² + x²`, `Vs = ΔR/Δt` 이다. 서스펜션 로깅은 한 시추공만 있으면 된다. SASW는 표면파 분산곡선을 역해석해 Vs 프로파일을 얻고, MASW는 다채널 능동, 상시미동(AAM)은 수동 방식이다.[S03]

**[암기]** N-Vs 경험식은 `Vs = 65.64·N^0.407`(Sun 2013), `144.7·N^0.380`(정남훈·이종규 2009), `98.38·N^0.29`(김동수 2003)이다.[S03]

::: summary 시험 포인트
1. SPT는 첫 15 cm를 버리고 뒤 30 cm의 타격수를 N으로 하며, `N60` 보정과 `(N1)60` 보정을 구분한다.
2. 점토는 VST로 Su를 구하되 `μ = 1.7 − 0.54 log PI` 로 보정하고 `qu = 2Cu` 이다.
3. CPT의 `cu = (qc − σo)/Nk`, `Nk = 15`(전기식 콘)를 외운다.
4. PMT의 `Es = 2(1+μs)·Gs`, `K0 = p0/σ'o` 를 구분한다.
5. DMT의 ID, ED, KD를 정의식으로 쓴다.
6. 다운홀의 `Vs = ΔR/Δt` 에서 R은 직선 거리이다.
:::

# 3. 토압

::: summary 한 줄 요약
벽이 흙에서 멀어지면 능동토압(최소), 흙 쪽으로 밀면 수동토압(최대), 움직이지 않으면 정지토압이며, 토압계수 `K = σ'h/σ'o` 가 핵심이다.
:::

## 3-1. 정지 · 능동 · 수동

**[개념]** 마찰 없는 벽 옆 흙 요소의 연직 유효응력은 `σ'o = γz` 로 놓는다. 수평 유효응력과의 비 `K = σ'h/σ'o` 를 상태별로 정지 `K0`, 능동 `Ka`, 수동 `Kp` 라 부르며, 파괴 기준은 `τf = c' + σ'·tanφ'` 를 쓴다.[S04]

**[암기]** 능동 상태에 필요한 벽 변위가 수동 상태보다 훨씬 작다.[S04]

| 흙 | 능동 ΔLa/H | 수동 ΔLp/H |
| --- | --- | --- |
| 느슨한 모래 | 0.001~0.002 | 0.01 |
| 조밀한 모래 | 0.0005~0.001 | 0.005 |
| 연약 점토 | 0.02 | 0.04 |
| 단단한 점토 | 0.01 | 0.02 |

## 3-2. 정지토압

**[공식]** `σ'h = K0·γz`. Jaky(1944): 정규압밀 `K0 = 1 − sinφ'`, 과압밀 `K0 = (1 − sinφ')·OCR^(sinφ')` 이다.[S04]

![정지토압 도식과 Jaky 식](../references/fig/L3_06.png "CIE3032 Lec 03 교안 PDF p.6"){wide}

**[패턴]** 지하수위가 있으면 전체 수평압은 유효수평응력 `σ'h` 에 간극수압 `u` 를 더한다. 수위 아래에서는 `σ'o = γH1 + γ'H2` (`γ' = γsat − γw`)를 쓰고 수압 `γw·H2` 는 따로 더한다.[S04]

## 3-3. Rankine 이론

**[개념]** 소성평형 상태는 흙덩이의 각 점이 파괴 직전이어서 모어 원이 파괴선에 접하는 상태다. 능동 상태에서 `sinφ' = CD/AC` 이고 `CD = (σ'o − σ'a)/2`, `AO = c'·cotφ'`, `OC = (σ'o + σ'a)/2` 이다.[S04]

![Rankine 능동. 모어 원과 파괴선](../references/fig/L3_13.png "CIE3032 Lec 03 교안 PDF p.13"){wide}

**[공식]** 능동 토압계수와 토압은 다음과 같다.[S04]

- `Ka = (1 − sinφ')/(1 + sinφ') = tan²(45° − φ'/2)`
- `σ'a = γz·Ka − 2c'·√Ka`
- 수동 `Kp = (1 + sinφ')/(1 − sinφ') = tan²(45° + φ'/2)`, `σ'p = γz·Kp + 2c'·√Kp`
- `Ka·Kp = 1`

**[필수]** 점착토의 능동토압은 지표에서 `−2c'√Ka`(인장)이다. 인장균열 깊이는 `zo = 2c'/(γ√Ka)`, `φ = 0` 이면 `zo = 2cu/γ` 이다. 균열 깊이 안에서는 흙과 벽이 접촉하지 않는다고 본다.[S04]

**[공식]** 합력은 다음과 같다. 점착이 없는 흙의 능동·수동 합력은 `Pa = ½·Ka·γH²`, `Pp = ½·Kp·γH²`이며 작용점은 바닥에서 `H/3` 이다. 파괴쐐기 각도는 능동 `45 + φ'/2`, 수동 `45 − φ'/2` 다.[S04]

![벽 압력 분포](../references/fig/L3_21.png "CIE3032 Lec 03 교안 PDF p.21"){wide}

**[공식]** 상재하중 q가 있고 수위가 있는 경우(`c' = 0`) 능동 합력은 다음과 같다.[S04]

`Pa = Ka·q·H + ½·Ka·γ·H1² + Ka·γ·H1·H2 + ½·(Ka·γ' + γw)·H2²`

수동은 `Ka` 대신 `Kp` 를 쓴다. 점착토는 다음과 같다.[S04]

- 능동(균열 무시) `Pa = ½·Ka·γH² − 2√Ka·c'·H`
- 능동(균열 고려) `Pa = ½·Ka·γH² − 2√Ka·c'·H + 2c'²/γ`
- 수동 `Pp = ½·Kp·γH² + 2√Kp·c'·H`

**[공식]** 경사 뒤채움(경사각 α, 마찰 없는 벽) Rankine은 `Ka = cosα·[cosα − √(cos²α − cos²φ')]/[cosα + √(cos²α − cos²φ')]` 이고 `Pa = ½·Ka·γH²`, 합력은 α 방향이다.[S04]

## 3-4. Coulomb 이론

**[개념]** Coulomb(1776)은 파괴면을 평면으로 가정하고 쐐기의 힘 평형으로 풀어 벽마찰과 경사 뒤채움을 고려한다. 시행쐐기법으로 각 β를 바꿔 가며 구한 Pa 중 최대값이 능동토압이다. 힘다각형에서 사인법칙으로 `Pa = W·sin(β − φ')/sin(90 + θ + δ' − β + φ')` 를 얻는다.[S04]

![Coulomb 능동. 시행 쐐기와 힘다각형(예제 13.5)](../references/fig/L3_43.png "CIE3032 Lec 03 교안 PDF p.43"){wide}

**[공식]** `Pa = ½·Ka·γH²` 이며 Ka는 다음과 같다.[S04]

`Ka = cos²(φ' − θ) / { cos²θ·cos(δ' + θ)·[1 + √( sin(δ' + φ')·sin(φ' − α) / (cos(δ' + θ)·cos(θ − α)) )]² }`

θ는 벽 뒷면의 연직 기울기, α는 뒤채움 경사, δ'는 벽 마찰각이다. `θ = α = δ = 0` 이면 Coulomb Ka는 Rankine Ka와 같다.[S04]

::: note
교안은 δ'를 φ'의 1/2~1/3로 적었다. 이 범위는 교안 표기를 그대로 옮긴 것이며 다른 문헌과 대조하지 않았다.
:::

**[암기]** Ka 표(θ = 0, α = 0, 행은 φ', 열은 δ' = 0, 5, 10, 15, 20, 25도)에서 자주 쓰는 행이다.[S04]

| φ' | δ'=0 | δ'=10 | δ'=20 |
| --- | --- | --- | --- |
| 30° | 0.3333 | 0.3085 | 0.2973 |
| 34° | 0.2827 | 0.2633 | 0.2549 |
| 40° | 0.2174 | 0.2045 | 0.1994 |

**[공식]** Coulomb 수동은 `Pp = ½·Kp·γH²` 이고 Kp는 `cos²(φ' + θ) / { cos²θ·cos(δ' − θ)·[1 − √( sin(φ' + δ')·sin(φ' + α) / (cos(δ' − θ)·cos(α − θ)) )]² }` 이다.[S04]

**[암기]** Kp 표(θ = 0, α = 0)의 일부이다. 열은 δ' = 0, 10, 20도이다.[S04]

| φ' | δ'=0 | δ'=10 | δ'=20 |
| --- | --- | --- | --- |
| 30° | 3.000 | 4.143 | 6.105 |
| 35° | 3.690 | 5.310 | 8.324 |
| 40° | 4.600 | 6.946 | 11.772 |

**[필수]** 벽마찰이 크면 평면 가정은 실제와 달라진다. 실제 파괴면은 곡선(BC)과 직선(CD)으로 이루어진다. 수동에서는 δ가 커질수록 오차가 커지고 비보수적이므로 `δ = 0` 해석을 쓴다. 비교하면 능동은 Coulomb이 Rankine보다 작고, 수동은 Coulomb이 더 크다.[S04]

| 항목 | Rankine | Coulomb |
| --- | --- | --- |
| 가정 | 응력 상태(소성평형) | 평면 쐐기 힘 평형 |
| 강도정수 | `c'`, `φ'` 모두 가능 | `c' = 0`(모래) |
| 능동 적용 | 모래, 점토 | 모래 |
| 수동 적용 | 모래, 점토 | 쓰지 않음 |

## 3-5. Log-spiral 수동, 지진, 옹벽

**[개념]** 로그나선 파괴면은 `r = r0·e^(θ·tanφ')` 이며 수동토압의 곡선 파괴면을 모사한다. 방사 전단영역과 Rankine 영역으로 나누고 O1 점 모멘트 평형 `W1·lW + Pd·l1 = P1·lP` 로 P1을 구한다. 시행면 P1, P2, ..., Pn 중 최소가 수동력 Pp다. Rankine 영역 힘은 `Pd = ½·γd²·tan²(45 + φ'/2)`, 작용점 `d/3` 이다.[S04]

**[공식]** 지진 시 능동토압(Coulomb 기반)은 `Pae = ½·γH²·(1 − kv)·Ka''`, `β̄ = tan⁻¹[kh/(1 − kv)]` 이다. kh와 kv는 수평, 연직 지진가속도를 g로 나눈 값이다.[S04]

![지진 시 Coulomb 능동 공식](../references/fig/L3_57.png "CIE3032 Lec 03 교안 PDF p.57"){wide}

**[암기]** 옹벽 종류는 중력식, 반중력식, 캔틸레버식, 부벽식이다. 파괴모드는 전도, 활동, 사면파괴(약한 지반)의 세 가지다. 보강토옹벽(MSE)은 금속 띠, 지오그리드, 돌망태, 콘크리트 패널로 구성한다.[S04]

## 3-6. 가설 흙막이 (Braced cut)

**[개념]** 굴착 중 임시 지지 구조이며 sheet pile, 띠장(wale), 버팀대(strut)로 이루어진다. 옹벽은 하나의 단위로 동시에 파괴되지만 굴착은 진행성 파괴이므로 Peck(1969)의 경험 토압도를 쓴다.[S04]

![Peck 경험 토압도(예제 14.2)](../references/fig/L3_65.png "CIE3032 Lec 03 교안 PDF p.65"){wide}

**[공식]** Peck 토압은 다음과 같다. 토압도의 형태는 위 그림 (a) 모래, (b) 연약~보통 점토, (c) 단단한 점토이다.[S04]

- 모래: `σa = 0.65·γ·H·tan²(45° − φ'/2)`, 전 깊이 일정
- 연약~보통 점토(`γH/cu > 4`): `σa = γH·(1 − 4cu/(γH))`, 상부 0.25H 증가 후 0.75H 일정
- 단단한 점토(`γH/cu ≤ 4`): `σa = 0.2γH ~ 0.4γH`, 0.25H 증가, 0.5H 일정, 0.25H 감소

**[패턴]** 버팀대 하중은 버팀대 사이를 단순보로 나눠 반력을 구하고, 반력에 수평 간격 s를 곱한다. 연습문제정리본의 예제 14.2에서 단계별로 푼다.[S04]

::: summary 시험 포인트
1. `Ka = tan²(45 − φ'/2)`, `Kp = tan²(45 + φ'/2)`, `Ka·Kp = 1` 을 즉시 쓴다.
2. 점착토는 `σ'a = γzKa − 2c'√Ka` 이며 인장균열 깊이 `zo = 2c'/(γ√Ka)` 를 구한다.
3. 수위가 있으면 수압을 따로 더하고, 층 경계에서 Ka가 바뀌면 토압이 불연속이다.
4. 합력의 작용점은 면적(삼각형, 직사각형)별 모멘트의 합을 합력으로 나눈 값이다.
5. Coulomb 수동은 쓰지 않고 `δ = 0` 해석을 쓴다.
6. Peck 토압은 모래 `0.65·γH·Ka`, 점토는 `γH/cu` 와 4의 비교로 구분한다.
:::

# 4. 사면안정

::: summary 한 줄 요약
사면의 안전은 안전율 `FS = τf/τd` 로 판정하고, 임계 활동면은 시행 활동면 중 FS가 최소인 것이다.
:::

## 4-1. 사면과 안전율

**[개념]** 사면은 자연사면과 인공사면(절토, 성토)으로 나뉘며 파괴 유형은 낙하(fall), 전도(topple), 활동(slide), 확산(spread), 흐름(flow)의 다섯 가지다. 이 강의는 활동을 다룬다.[S05]

![사면 활동 파괴와 시행 활동면](../references/fig/L4_21.png "CIE3032 Lec 04 교안 PDF p.21"){wide}

**[개념]** 한계평형법은 활동 질량과 활동면에서 흙이 파괴 상태라고 보고, 전단저항을 FS로 나눠야 평형이 되는 값을 구한다. `FS = τf/τd = (c' + σ'·tanφ')/(c'd + σ'·tanφ'd)` 이다.[S05]

**[공식]** 점착력 안전율 `Fc' = c'/c'd`, 마찰 안전율 `Fφ' = tanφ'/tanφ'd` 이며 같게 두면 `FS = Fc' = Fφ'` 이다.[S05]

**[암기]** `FS < 1` 불안정, `FS = 1` 한계 안정, `FS > 1` 안정이다. 설계 요구는 `FS > 1.5` 이다. 시행 활동면 여러 개를 계산해 최소 FS를 답으로 삼는다.[S05]

## 4-2. 무한사면

**[개념]** 두께 H, 경사 β인 얇은 사면 요소다. 폭 L인 요소의 무게는 `W = γLH`, 활동면 수직력 `Na = W·cosβ`, 평행력 `Ta = W·sinβ` 이다.[S05]

**[공식]** 건조 또는 침투 없는 경우 다음과 같다.[S05]

- `σ' = γH·cos²β`, `τ = γH·cosβ·sinβ`
- `FS = c'/(γH·cosβ·sinβ) + tanφ'/tanβ`
- `c' = 0` 이면 `FS = tanφ'/tanβ`, 모래는 안식각이 마찰각과 같을 때까지 서 있다

**[공식]** 지하수위가 사면 지표와 평행하게 침투하는 경우 등수두선은 사면에 수직이고, 바닥 간극수압력은 `Ubase = γw·L·H·cosβ` 이다. 유효수직력 `N' = γ'·LH·cosβ` 이므로 다음 식을 얻는다.[S05]

`FS = c'/(γsat·H·sinβ·cosβ) + (γ'/γsat)·(tanφ'/tanβ)`

![무한사면 침투. 힘 삼각형과 FS 식](../references/fig/L4_26.png "CIE3032 Lec 04 교안 PDF p.26"){wide}

**[스킬]** 침투가 있으면 `γ'/γsat` 이 마찰항에 곱해져 FS가 줄어든다. 점착항은 `γ → γsat` 로 바뀐다.[S05]

## 4-3. 평면 파괴 (Culmann)

**[공식]** 높이 H, 사면각 β, 파괴면각 θ, `L = H/sinθ` 일 때 다음과 같다.[S05]

- `W = ½γH²·(tanβ − tanθ)/(tanθ·tanβ)`
- `FS = c/[½γH·((tanβ − tanθ)/(tanθ·tanβ))·sin²θ] + tanφ/tanθ`

![Culmann 평면 파괴 쐐기와 힘의 분해](../references/fig/L4_30.png "CIE3032 Lec 04 교안 PDF p.30"){wide}

**[패턴]** 임계 파괴면은 FS가 최소인 θ다. 특별한 경우는 다음과 같다.[S05]

- `c = 0`: `FS = tanφ/tanθ` 이며 θ가 커질수록 줄어든다. `θ = β` 에서 `FSmin = tanφ/tanβ` 이다. 점착 없는 흙은 마찰각보다 급한 사면으로 서지 못한다.
- `φ = 0`(비배수 점토): `θcrit = β/2` 이다. 수직 절취(`β = 90°`)에서는 `FSmin = 4Su/(γH)`, 임계높이 `Hc = 4Su/γ` 이다.

::: note
교안의 `φ = 0` 일반 사면 `FSmin` 식은 분자의 부호가 앞뒤 식과 일치하지 않아 옮기지 않았다. θcrit = β/2 와 수직 절취 결과만 사용한다.
:::

**[공식]** `c-φ` 흙에서 `FS` 를 c'와 φ' 모두에 적용한 값 `c'd`, `φ'd` 로 풀면 다음과 같다.[S05]

- `c'd = (γH/4)·[1 − cos(β − φ'd)]/(sinβ·cosφ'd)`
- `θcr = (β + φ'd)/2`
- `Hcr = (4c'/γ)·[sinβ·cosφ'/(1 − cos(β − φ'))]`
- 안정수 `m = c'd/(γH) = [1 − cos(β − φ'd)]/(4·sinβ·cosφ'd)`

## 4-4. 원호 파괴

**[암기]** 원호 활동면은 세 가지다. 선단원(toe circle)은 선단을 지나고, 사면원(slope circle)은 선단 위를 지나며, 중점원(midpoint circle)은 선단 아래 깊은 곳을 지난다(기초 파괴, base failure).[S05]

![원호 파괴면의 세 유형](../references/fig/L4_40.png "CIE3032 Lec 04 교안 PDF p.40"){wide}

**[개념]** 해석법은 두 종류다. 매스법(mass procedure)은 활동면 위 흙덩이를 하나로 보며 균질한 흙에 유용하다. 절편법(method of slices)은 수직 절편으로 나눠 흙과 간극수압의 변화를 반영한다.[S05]

**[공식]** 균질 점토, `φ = 0` 에서 중심 O, 반경 r, 중심각 θ일 때 `MR = cu·r²·θ` 이고 `Md = W1·l1 − W2·l2` 이므로 `Fs = cu·r²·θ/(W1·l1 − W2·l2)` 이다. 안정수 `m = cd/(γH)`, 임계높이 `Hcr = cu/(γ·m)` 이다.[S05]

![안정수 차트(Fig 15.13)와 D 정의](../references/fig/L4_44.png "CIE3032 Lec 04 교안 PDF p.44"){wide}

**[필수]** 안정수 도표 사용 규칙이다.[S05]

- `β > 53°` 이면 모두 선단원이다
- `β < 53°` 이면 깊이비 `D = (사면 꼭대기에서 견고한 지반까지 수직거리)/(사면 높이)` 에 따라 선단, 사면, 중점원이 갈린다
- 선단원 중심 위치는 β > 53° 에서 곡선(α, θ), β < 53° 에서 표 15.1로 읽는다

| 사면비 n' | β | α1 | α2 |
| --- | --- | --- | --- |
| 1.0 | 45° | 28° | 37° |
| 1.5 | 33.68° | 26° | 35° |
| 2.0 | 26.57° | 25° | 35° |
| 3.0 | 18.43° | 25° | 35° |
| 5.0 | 11.32° | 25° | 37° |

::: note
도표에서 읽는 m 값은 그림을 읽은 것이어서 정밀도가 낮다. 시험에서는 문제에 주어진 값을 쓴다.
:::

![선단원 중심 위치 곡선과 표 15.1](../references/fig/L4_45.png "CIE3032 Lec 04 교안 PDF p.45"){wide}

## 4-5. 절편법

**[개념]** 활동체를 N개의 수직 절편으로 나누고 바닥을 직선으로 근사한다. 절편 무게는 사다리꼴로 근사한다. 절편에는 자중 W, 절편간 힘, 바닥 접선 저항 T, 유효 수직반력 P', 간극수압력 `U = u·L` 이 작용한다.[S05]

**[공식]** 보통절편법(OMS, Fellenius)은 절편간 합력이 절편 바닥에 평행하다고 가정한다. 바닥 수직방향 힘평형에서 `P' = W·cosα − U` 이고, O점 모멘트 평형에서 `ΣW·R·sinα = R·ΣT` 이므로 다음 식을 얻는다.[S05]

`FS = Σ[c·L + (W·cosα − U)·tanφ] / ΣW·sinα`

상재하중 q가 있으면 `W → W + Q` 로 바꾼다. 사면이 수침되면 부력단위중량 γ'를 써 간극수압을 직접 다루지 않는다.[S05]

**[공식]** 단순 Bishop(simplified)은 절편간 힘의 연직 성분이 0이라고 가정한다. 연직 힘평형으로 P'를 구해 대입하면 FS가 양변에 나타나므로 반복 계산한다.[S05]

`FS = Σ{ [c·L·cosα + (W − U·cosα)·tanφ] / [cosα + tanφ·sinα/FS] } / ΣW·sinα`

![보통절편법 해 표와 FS 계산](../references/fig/L4_61.png "CIE3032 Lec 04 교안 PDF p.61"){wide}

**[필수]** Bishop은 원호 파괴면에만 적용해야 정확도가 유지된다. 같은 사면에서 Bishop(1.66)이 OMS(1.59)보다 크므로 OMS가 더 보수적이다. Bishop은 후속 복잡한 방법과 정확도가 비슷하다고 교안은 적고 있다.[S05]

| 방법 | 힘평형(x, y) | 모멘트평형 |
| --- | --- | --- |
| OMS, Bishop simplified | 만족 안 함 | 만족 |
| Janbu simplified, Corps of Eng. | 만족 | 만족 안 함 |
| Bishop rigorous, Spencer, Morgenstern-Price | 만족 | 만족 |

**[개념]** 실제로는 임계 활동면의 크기와 위치를 미리 알 수 없어 전용 프로그램(PCSTABL, Slope/W)으로 많은 시행면을 계산한다. Spencer(1967), Morgenstern & Price(1965)의 엄밀법은 임의 형상 활동면에 쓴다.[S05]

## 4-6. Swedish circle 응용

**[공식]** 점토 위 띠기초의 지지력 `qbL = Nc·su` 를 활동원 모멘트 평형으로 구하면 `Nc = 4α/sin²α` 이다. `dNc/dα = 0` 이면 `α = tanα/2` 이고, 반복 `α_new = atan(2α)` 로 `α ≈ 1.166 rad (66.81°)` 가 나오며 `Nc,min = 5.52` 이다. 소성이론의 5.14보다 크다.[S05]

::: summary 시험 포인트
1. 무한사면 건조 `FS = c'/(γH·cosβ·sinβ) + tanφ'/tanβ`, 침투는 `γ'/γsat` 와 `γsat` 를 바꿔 쓴다.
2. Culmann에서 `c = 0` 이면 `FSmin = tanφ/tanβ`, `φ = 0` 이면 `θcr = β/2`, 수직 절취 `4Su/(γH)` 이다.
3. `c-φ` 흙은 `c'd`, `φ'd` 로 푼다. 동일한 FS를 c'와 tanφ' 모두에 적용한다.
4. OMS는 `P' = W·cosα − U`, Bishop은 반복해서 FS를 구한다.
5. 안정수 도표는 `β > 53°` 이면 선단원이다. `Hcr = cu/(γ·m)` 이다.
6. 설계 요구 `FS > 1.5`, 시행 활동면 중 최소 FS가 답이다.
:::
