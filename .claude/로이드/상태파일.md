# `상태.md` · `기록.md` 양식

`상태.md`에는 재개에 필요한 것만 둔다. 세션 시작 때 첫 3줄만 읽으므로, **판단에 필요한 것을 첫 3줄에** 둔다.
지나간 판정과 해소된 쟁점은 `기록.md`로 옮긴다.

## 상태.md
```markdown
# <작업ID> — <한 줄 주제> · 모드: DOCUMENT|PRESENTATION
상태: 진행 중 <단계> | 사용자 승인 대기 | 완료 | 중단
다음에 할 일: <한 줄>

## 요청      독자 / 분량 / 형식 — 상세는 workspace/00
## 기획      개정 번호 r1 · 핵심 메시지 · 질문 수
## 진행      | 단계 | 산출물 | 상태 | 비고 |  (00·01 / 02 / 03·04·05 판정 / DOC 07 또는 PPT 06·07 / 산출·기계 검사 / Lite Review·교차 확인)
## 세션      요르 조사 세션 ID · 요르 기획 세션 ID · 유리 에이전트 · 아냐 에이전트 · 실제 모델(확인 불가면 미확인)
## 열린 것   검증 라운드 0/1 · 자료 보완 0/1 · 채택할 것 · REMOVE·CAUTION 목록 · 교차 확인 n/n · 사용자 결정 대기
```

## 기록.md
시간순으로 **덧붙이기만** 한다. 남길 것은 호출(모델·세션·종료 코드), 헤더 수치, 판정과 이유, 채택 결정, 반려,
교차 확인 결과(값 · 근거 ID · 원문 대조), 강도를 내린 문장의 원문과 수정문, 실패한 호출과 원인, 사용자에게 올린 것과 답이다.
