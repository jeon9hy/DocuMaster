# 절차 — 비주얼 기획 PRESENTATION (요르 06B) · 출력 `07_notebooklm_presentation_pack.md`

06 기획 세션을 resume해서 부른다. 06의 메시지를 시각 언어로 옮긴 결과가 곧 NotebookLM 발표팩이다.
기준은 06에서 이미 받은 `공통/발표규격.md`다.

## 1. 원칙
- **새 사실을 넣지 않는다.** 06과 05만 쓴다. 06의 개수·순서·메시지·한정·금지선은 바꾸지 않는다. 바꿔야 하면 끝의 「06에 올릴 문제」에 적는다.
- 시각 결정(구성, 제목 생략, 줄바꿈 위치)은 네 권한이다.
- Art Direction은 이 주제와 청중에서 나온다. 이전 작업의 팔레트·모티프를 가져오지 않는다. `references/`는 품질 기준(위계·여백·스케일)으로만 보고,
  사용자가 "이 스타일로"라고 했을 때만 따라 한다.
- 톤·이미지 비중은 브리프 「디자인 방향」대로다. 캐릭터 IP·엔터테인먼트는 친근한 톤에 일러스트 중심, 정책·재무는 절제된 톤에 데이터 중심.
- 자산은 05에 출처가 있는 것과 사용자가 준 것(`자료/`·`references/`)만 쓴다. 새 이미지를 찾으러 나가지 않는다.

## 2. NotebookLM이라는 렌더러
- 슬라이드 한 장을 통째로 이미지로 새로 그린다(E-017). 준 이미지를 붙이지 않는다. 외형은 **글로 준 묘사가 전부다.**
- 일러스트를 잘 그린다. 브리프가 그림을 허용하면 장면 일러스트를 적극적으로 시킨다(최종 편집에서 교체한다).
- **항목 안의 줄바꿈을 무시한다.** 화면의 한 줄 = 목록 항목 하나.
- 팩에 쓴 것은 화면에 나온다고 가정한다. 화면 필드와 화면 밖 필드를 섞지 않는다.

## 3. 형식 — 도구가 `슬라이드 수:`와 `# 제작 지시`를 읽는다

```markdown
# Presentation Pack
- 작업 ID / 기획 개정 번호 / 근거: 05 · 06
- 슬라이드 수: n
--- 헤더 끝 ---

## Art Direction
- 톤·인상: 청중이 덱 전체에서 받을 인상 한 문장
- 색: 배경 / 글자 / 보조 글자 / 강조 / 한정 표시 — HEX와 각 색의 의미
- 서체: 한 가족. 크기 단계 Hero / 제목 / 핵심 문장 / 본문 / 캡션
- 레이아웃: 본문 장 제목의 위치·크기(모든 장 동일) · 좌우 여백 · 캡션 위치(왼쪽 아래)
- 화풍: 선·채색·명암·비율 한 가지
- Character Model: 이름 · 식별 요소 3~5개 한 줄 · 외형 근거(자산 ID / 05 근거 ID / 없음) — 캐릭터가 없으면 "없음"
- 모티프: 덱을 묶는 반복 요소 1~2개 (표지와 마지막 장을 잇는 것 포함)
- 피할 것: 이 주제에서 피할 분위기와 범용 PPT 패턴

## Deck Rhythm
1 오프닝·Hero 일러스트·강 → 2 질문·큰 문장·중 → … (장마다 Beat · 주인공 요소 · 강도)

## 자산
A01 · 내용 · 출처 · 상태 · 쓰는 장 (없으면 "검증된 자산 없음")

---

## Slide 1 — 오프닝
### 화면
- 주인공: 무엇을 · 화면의 몇 % · 어디에. 누가 무엇을 하는 장면이고 어떤 분위기인지까지
- 구성: 제목·문구·주인공의 위치와 정렬, 여백이 남는 곳
- 캐릭터: 등장하면 Character Model 문장을 **그대로** 쓴다 (요약·참조 금지)
### 제목
- 첫 줄
- 둘째 줄
### 화면 문구
- 한 줄 = 한 항목
### 출처
자료: 기관·자료명 (연도)
### 한정
없음
### 최종 편집
공식 이미지로 교체할 자리 (자산 ID·위치) 또는 "없음"
### 발표자 메모
(06의 발표자 메모 + 앞뒤 장 연결)
### 근거
S01, S03

(Slide마다 반복. 비는 필드는 "없음")

# 제작 지시
(아래 §4 블록을 그대로 적는다 — 도구가 NotebookLM 프롬프트로 넣는다)
```

## 4. 제작 지시 블록 — 그대로 옮긴다

```text
이 자료를 문서형 PPT로 옮기지 마세요. 슬라이드마다 「화면」의 주인공을 먼저, 화면의 절반 이상을 차지하게 크게 그리세요.
넓은 여백에 작은 글자 한 줄이나 작은 인물 하나만 두지 마세요.
덱 전체를 Art Direction의 색, 서체 한 가족, 화풍 하나로 통일하세요. 본문 장의 제목은 모두 같은 크기, 같은 위치에 두세요.
「제목」과 「화면 문구」의 항목 하나가 화면의 한 줄입니다. 그 위치에서만 줄을 바꾸고, 문구를 바꾸거나 합치지 마세요.
「제목」이 "없음"인 장에는 제목을 만들지 마세요. 같은 문장을 제목과 캡션에 두 번 쓰지 마세요.
「출처」가 "없음"인 장에는 출처를 쓰지 마세요. 출처는 왼쪽 아래 작은 한 줄로, 테두리나 진한 바 없이 쓰세요.
「한정」은 관련 숫자 바로 옆에 한 줄로 두세요.
「발표자 메모」「근거」「최종 편집」「Deck Rhythm」「자산」은 화면에 표시하지 말고 슬라이드로 만들지도 마세요.
첫 장은 발표의 얼굴로 만들고, 마지막 장은 첫 장의 모티프를 받아 결론 한 문장으로 닫으세요.
인물과 장면은 그림으로, 관계·순서·수치는 도식·연표·큰 숫자로 보여 주세요. 텍스트를 카드나 박스에 나눠 담지 마세요.
캐릭터는 「화면」의 묘사대로, 모든 장에서 같은 모습으로 그리세요. 외형 근거가 "없음"인 캐릭터는 소품이나 실루엣으로 표현하세요.
로고, "공식" 표기, 실존 인물의 사진풍 얼굴은 만들지 마세요. Slide Title 같은 자리표시자를 남기지 마세요.
업로드된 자료에 없는 사실·수치·인용을 추가하거나 계산하지 마세요. 슬라이드 순서와 메시지를 바꾸지 마세요.
```
