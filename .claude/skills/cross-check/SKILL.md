# 교차 확인 — 마지막 보루

검증은 1라운드뿐이었다. 대상이 애매하면 **넓히는 쪽으로** 판단한다.

## 1. 고르기
doc-finish·deck-review의 정독 때 `기록.md`에 적어 둔 후보 목록을 쓴다 — **07을 다시 통째로 읽지 않는다.**
목록이 없으면 07에서 고른다. 기본 5건(적으면 전부, 많으면 늘린다). 우선순위: 요약·결론의 수치 → 제목·Main Message의 수치 →
인용문 → 기관명·인명·직함 → 표·차트의 대표값.

## 2. 값 대조
05 §3에서 근거 ID를 찾고, 소재를 **직접 연다**(근거표 요약은 확인이 아니다). 값·기준 시점·단위·집계 범위를 함께 본다. 계산값은 다시 계산한다.

## 3. 강도 검사 — 대조로는 통과하는 오류 (E-021)
요약·결론·Main Message·권고를 **읽고** 본다.
- 상관·전후 비교를 인과("때문이다·결정적·덕분에")로 올렸는가 → 상관 서술로 내린다
- 권고의 기대효과를 확정("입증됐다·개선된다")으로 썼는가 → "~을 목표로 한다"로 내린다
- 근거의 집계 범위보다 넓게 일반화했는가 → 범위를 좁힌다
- 05의 `[부분확인]`·CAUTION이 단정문이 됐는가 → 조건을 되살린다
- 05·06에 식이 없는 계산값이 있는가 → 새 수치다. 지운다

## 4. 함께 닫기
`gate_check.py "$ID" 07`의 결과(CAUTION 글자 일치 · REMOVE 근거 ID · 06의 개수와 순서)를 확인한다. 스크립트가 못 잡는 것 — 표현만 바뀐 REMOVE, 발표팩에서 줄인 CAUTION의 뜻 — 은 읽어서 본다.

## 5. 처리
전부 일치하면 기록하고 닫는다. **한 건이라도 어긋나면 같은 유형 전체를 다시 본다.** 근거를 열 수 없으면 CAUTION이나 REMOVE로 내린다.
조사에 없던 사실이 나오면 삭제하고 사용자에게 보고한다. 확인한 것과 **확인하지 않은 것**을 `기록.md`에 남긴다.
