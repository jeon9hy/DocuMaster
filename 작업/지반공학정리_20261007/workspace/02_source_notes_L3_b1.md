# L3 노트 pp.13–24 (쪽=PDF쪽)
- p13 Rankine 능동 유도: sinφ'={(σ'o−σ'a)/2}/{c'cotφ'+(σ'o+σ'a)/2} → c'cosφ'+(σ'o+σ'a)/2·sinφ'=(σ'o−σ'a)/2 → σ'a=σ'o(1−sinφ')/(1+sinφ') − 2c' cosφ'/(1+sinφ') [그림 p13 Mohr 원 크롭 후보]
- p14 σ'a=γz tan²(45−φ'/2) − 2c' tan(45−φ'/2) ; **Ka=σ'a/σ'o=(1−sinφ')/(1+sinφ')=tan²(45−φ'/2)** ; 간단형 σ'a=γ'zKa−2c'√Ka (유효), σa=γzKa−2c√Ka (전응력)
- p15 인장균열: 점착토 능동토압 z=0에서 −2c'√Ka(인장). γ'zKa−2c'√Ka=0 → 균열 깊이 zo=2c'/(γ√Ka) [그림 p15: 압력도와 45+φ'/2 파괴면 격자]
- p16 Rankine 수동: σ'p=σ'o tan²(45+φ'/2)+2c' tan(45+φ'/2)=γz tan²(45+φ'/2)+2c' tan(45+φ'/2) ; σ'p=γ'zKp+2c'√Kp ; **Kp=σ'p/σ'o=(1+sinφ')/(1−sinφ')=tan²(45+φ'/2)** (Ka·Kp=1) [그림 p16 Mohr 원]
- p17 수동 압력도: 점착 있으면 z=0에서 2c'√Kp 부터 시작, +γzKp 증가 (사다리꼴). 파괴선 격자 45−φ'/2
- p18 경사 뒤채움(Rankine, 마찰 없는 벽, 경사 α): Ka=cosα·[cosα−√(cos²α−cos²φ')]/[cosα+√(cos²α−cos²φ')]; Pa=½KaγH² (합력은 α 방향, 벽 법선에 α 기울어짐). Kp=cosα·[cosα+√(cos²α−cos²φ')]/[cosα−√(cos²α−cos²φ')]; Pp=½γH²Kp
- p19 벽 압력 분포(c'=0): 능동 σ'a=KaγH, Pa=½KaγH² (작용점 H/3, 파괴쐐기 45+φ'/2). 수동 σ'p=KpγH, Pp=½KpγH² (45−φ'/2) [그림 p19 크롭 후보]
- p20 부분수침 + 상재하중 q, 능동(c'=0): 상단 σ'a=qKa; 수위면 σ'a=Ka(q+γH1); 바닥 σ'a=Ka(q+γH1+γ'H2); 수압 u=γwH2. 합력 Pa=KaqH+½KaγH1²+KaγH1H2+½(Kaγ'+γw)H2² [그림 p20~21 크롭 후보]
- p21 수동 동일 구조: Pp=KpqH+½KpγH1²+KpγH1H2+½(Kpγ'+γw)H2²
- p22 점착토 능동: σ'a=KaγZ−2√Ka c'; zo=2c'/(γ√Ka); φ=0이면 zo=2cu/γ. 전체 합력(균열 무시): Pa=½KaγH²−2√Ka c'H (φ=0: ½γH²−2cuH)
- p23 인장균열 고려: 균열 깊이 zo까지 흙-벽 접촉 없음 → Pa=½(KaγH−2√Ka c')(H−2c'/(γ√Ka)) = ½KaγH²−2√Ka c'H+2c'²/γ ; φ=0: Pa=½γH²−2cuH+2cu²/γ [그림 p23: 압력도 차감]
