## 도구·환경

- **E-003** PyMuPDF 기본 폰트는 한글을 "..."로 그린다(텍스트 추출은 정상) → 텍스트 추출은 시각 확인을 대신하지 않는다
- **E-004** 기계 검사는 표 잘림·쪽 나눔·폰트 폴백을 못 잡는다 → 해당 쪽을 PNG로 본다
- **E-005** Git Bash에서 python 한글 출력이 깨진다 → `PYTHONIOENCODING=utf-8`. 파일은 멀쩡하다
- **E-006** 커스텀 `subagent_type`은 인식되지 않는다 → `general-purpose` + 역할 파일 경로(에이전트가 직접 읽는다). CLAUDE.md는 서브에이전트에 자동으로 실린다

- **E-008** Codex가 셸로 한글 파일명을 읽으면 깨진다 → 파일별 자체 읽기. workspace 파일명은 ASCII

- **E-013** Codex 사용량 한도는 계정 단위다(모델 무관, E-034) → 기다리거나 사용자에게. 검증 도중 막히면 사용자 승인 뒤 대행(E-033)

## 설계 결정 — 왜 이 규칙이 있나
- **E-020** (PPT) 06 세부 기획을 07 앞에 둬서 발표팩 작성자가 구조를 정하지 않게 했다. DOC는 아냐가 00·05로 직접 설계한다
- **E-021** 수치가 다 맞아도 결론만 세지는 오류(인과·확정)는 대조로 안 잡힌다 → 강도 검사(cross-check §3)
- **E-023** 상한(질문 10·출처 3)은 천장이다. 못 본 것을 보고하게 해서 막는다
- **E-026** 06에 형식 이름(표·카드)을 쓰면 표·카드 덱이 된다 → 내용(06)과 시각(07 발표팩)을 나눴다
- **E-027** 문서 PDF도 편집 디자인을 한다(md2html 편집 요소)
- **E-029** 사용자가 말하지 않은 제한(텍스트 위주)을 로이드가 넣어 덱이 글자판이 됐다 · 추상 선은 이미지가 아니다 · NotebookLM은 항목 안 줄바꿈을 무시한다 · 조사 세션 resume으로 06이 57만 토큰
- **E-031** 비율을 채우려는 장면 금지 · Character Model 한 줄을 모든 장에 반복 · 외형 근거가 없으면 소품·실루엣
- **E-036** Character Model을 참조로 줄이는 관성이 있다 → grep으로 센다
- **E-041** `gate_check.py`: 05에 없는 수치·REMOVE ID·CAUTION 글자 일치·LOCKED·Character Model·출처를 기계로 본다. 좌표 줄과 한 자리 수, 표현만 바꾼 REMOVE는 못 잡는다
- **E-042** 렘 v02 NotebookLM: 글자가 그림 위·%분할 구도·긴 Hero 줄 화면 밖·출처 누락 → 글자 자리·분할 금지·줄 한도·출처 필수(v03 확인)
- **E-043** 규격이 스토리 기준이었다 → 00에서 덱 유형을 정한다. 사용자 레퍼런스는 **구조만** 뽑는다(색·아이콘을 규칙에 박으면 모든 덱이 그 모양)
- **E-044** 발표규격에 스토리 전용 문장이 공통으로 남아 근거형과 충돌 → 공통에는 모든 유형에 참인 것만
- **E-045** 치이카와·렘 둘 다 크림 배경 — 지침에 없는 모델 취향. 주제 색은 강조·장치에, 배경은 내용이 읽히게. 크림을 고르면 이유를 적는다
- **E-046** 렘 v03(사용자 평: 최고): NotebookLM은 **반복해 적은 것은 지키고 한 번 적은 것은 사전 지식으로 되돌아간다** → 스토리 화풍 장마다 반복, 틀리기 쉬운 요소 + `- 강조:`, 근거 없는 인물은 검은 실루엣. 공식 외형과 맞는 추가 세부는 통과
- **E-047** 절차서의 스토리 문장이 학술·브리핑과 충돌 → `공통/발표_스토리|브리핑|학술.md`로 나누고 **작업마다 유형 파일 하나만 싣는다**
- **E-048** 덱 유형은 목적으로 고른다(사용자 명시 > 맥락 > 목적 > 청중 행동 > 소재). 유형 누락과 00→06→07 불일치는 FAIL

- **E-050** nlm_pipeline은 제작 지시가 없으면 멈춘다(스토리 편향 fallback 제거) · 슬라이드 형식은 검증된 detailed_deck만 쓴다 · 사용자가 명시한 형식 요구가 디자인 기본값을 이긴다(사실·출처·CAUTION·LOCKED는 예외)
