# 발표 규격 (PRESENTATION) — 좋은 초안

요르 06·06B가 이 기준으로 설계하고, 로이드가 deck-review와 Render Gate에서 판정한다.
목표는 **최종 편집이 쉬운 초안**이다. 선·비율의 작은 차이는 통과, 사실 오류·외형 오류·노출된 검증 문단은 불통과다.

## 1. 흐름 — 완결성이 먼저다
- 덱은 이야기 하나다. Main Message만 이어 읽어도 발표가 된다. 목차 낭독이면 실패다.
- 표지는 주제의 얼굴이다. 가장 강한 이미지나 문장 하나로 톤을 세운다. 2장은 왜 들어야 하는지(질문·갈등)를 연다.
- 마지막 장은 요약 목록이 아니라 **결론 한 문장**이다. 표지의 모티프를 받아 닫는다. 결론 뒤에 새 정보나 "감사합니다" 단독 장을 두지 않는다.
- 강한 장(이미지·큰 숫자·한 문장)과 설명 장(도식·데이터)을 번갈아 둔다. 같은 강도가 세 장 넘게 이어지지 않는다. 절정은 2/3~3/4 지점이다.
- 장수는 브리프대로. 없으면 내용에 맞추되 15~20장이 상한이다. 근거 없는 장은 만들지 않는다.

## 2. 화면 — 주인공 하나가 화면을 장악한다
- 장마다 주인공 하나(큰 타이포·일러스트/사진·큰 숫자·그래프·도식·표). 3초 안에 시선이 간다.
- **비데이터 장에서 주인공은 화면의 50% 이상이다.** 넓은 여백에 작은 글자 한 줄이나 작은 캐릭터 하나만 두지 않는다.
  한 문장이 주인공이면 Hero 크기로 키운다.
- 인물·장면·분위기는 그림으로, 관계·순서·수치는 도식·연표·큰 숫자로. 도식 장에 캐릭터를 장식으로 끼우지 않는다.
- 표현 선택 순서: 실제 이미지·장면 → 타이포·스케일 → 도식 → 데이터 → 은유(무엇을 상징하는지 말할 수 있을 때만) → 표.
- 표는 3개 이상 대상 × 2개 이상 기준 비교일 때만. **같은 레이아웃은 2장 연속 금지, 덱 전체에서 2회까지.**
- 이미지 비중은 브리프 「디자인 방향」을 따른다. "높음"이면 70% 이상의 장에서 일러스트·사진이 주인공이다.
  추상 선·점은 이미지가 아니다. 모자라면 장별로 이유를 적는다 — "검증된 이미지가 없어서"는 이유가 아니다(NotebookLM이 그린다).
  비율을 채우려고 도식 장에 장면을 끼우지 않는다(E-029·E-031).
- 통일감: 화풍 하나, 색 체계 하나, Layout Grid(제목 위치·좌우 여백·캡션 위치) 하나. 다양함은 주인공에서만 나온다.

## 3. 글자
- 서체는 한 가족이고 굵기로 위계를 만든다. Hero 제목만 두 번째 서체를 쓸 수 있다.
- 크기는 Hero / 제목 / 핵심 문장 / 본문 / 캡션 5단계뿐이다. 본문 장 제목은 크기와 위치가 모두 같다. 캡션·한정도 실제 크기에서 읽혀야 한다.
- **줄은 호흡 단위로 끊는다.** 조사·수식어 뒤에서 끊지 않는다. 「언니의 대체품이 / 아니야」 ○ · 「언니의 대체 / 품이 아니야」 ✗
- 제목은 선택이다. 그림이 말하는 장은 제목 없이 둔다. 같은 문장을 제목과 화면 문구에 두 번 쓰지 않는다.
- 본문은 최대 3그룹 × 1~2줄, 한 줄에 사실 하나. 붐비면 글자를 줄인다(폰트부터 줄이지 않는다). 앞 장에 나온 사실을 다시 쓰지 않는다.

## 4. 출처와 한정
- 출처는 통계·설문·순위·수치·직접 인용·논쟁적 주장 장에만 단다. 장면·줄거리·분위기 장의 참조는 발표자 메모로 보낸다.
- 왼쪽 아래 작은 한 줄, 사람이 읽는 기관·자료명으로 쓴다: `자료: Character JAPAN 설문 (2016)`. `[S01]`·URL·테두리·진한 바는 쓰지 않는다.
  오른쪽 아래는 워터마크 자리다.
- 한정은 필요할 때만, 해당 수치 바로 옆에 한 줄(30자 이내)로 단다. 긴 조건·검증 경위는 발표자 메모로. 출처와 한정을 합치지 않는다.

## 5. 캐릭터·인물
- 이름을 붙인 그림은 외형을 주장한다. 근거는 `references/` 이미지와 05의 공식 묘사뿐이다. 없으면 종·색·무늬를 짐작하지 않고 소품이나 단순 실루엣으로 둔다.
- 반복 캐릭터는 Character Model 한 줄(식별 요소 3~5개)로 고정하고, **등장하는 모든 장에 같은 문장을 그대로** 쓴다(E-036).
- 로고, "공식" 표기, 실존 인물의 사진풍 얼굴은 만들지 않는다.

## 6. 재작업 대상 — 요르 제출 전 점검 · deck-review · Render Gate가 같이 쓰는 목록
