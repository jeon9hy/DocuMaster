# 절차 — 비주얼 기획 PRESENTATION (요르 06B) · 출력 `07_notebooklm_presentation_pack.md`

06 세션을 resume해서 부른다. 결과가 곧 NotebookLM 발표팩이고, 기준은 06에서 받은 `공통/발표규격.md`와 덱 유형 파일(`발표_<유형>.md`)이다.

## 1. 원칙
- **새 사실을 넣지 않는다.** 06과 05만 쓴다. 06의 개수·순서·메시지·한정·금지선은 바꾸지 않는다. 바꿔야 하면 「06에 올릴 문제」에 적는다.
- 시각 결정(구성, 줄바꿈 위치, 유형 파일이 허용하면 제목 생략)은 네 권한이다.
- Art Direction은 이 주제와 청중에서 나온다. 이전 작업의 팔레트·모티프를 가져오지 않는다. `references/`는 사용자가 "이 스타일로"라고 했을 때만 따라 한다.
- 흐름·톤·이미지·출처는 유형 파일과 브리프 「디자인 방향」대로다.
- 자산은 05에 출처가 있는 것과 사용자가 준 것만 쓴다. 새 이미지를 찾지 않는다.

## 2. NotebookLM이라는 렌더러
- 장을 통째로 이미지로 새로 그린다(준 이미지를 붙이지 않는다, E-017). 외형은 **글로 준 묘사가 전부다.**
- 그림을 잘 그린다. 그림을 시킬지, 얼마나 시킬지는 유형 파일 §5대로다.
- **항목 안의 줄바꿈을 무시한다.** 화면의 한 줄 = 목록 항목 하나.
- 팩에 쓴 것은 화면에 나온다고 가정한다. 화면 필드와 화면 밖 필드를 섞지 않는다.

## 3. 형식 — 도구가 `슬라이드 수:`와 `# 제작 지시`를 읽는다

```markdown
# Presentation Pack
- 작업 ID / 기획 개정 번호 / 근거: 05 · 06
- 덱 유형: 스토리 | 학술 | 브리핑
- 슬라이드 수: n
--- 헤더 끝 ---

## Art Direction
- 톤·인상: 덱 전체의 인상 한 문장
- 색: 배경 / 글자 / 보조 글자 / 강조(유형 파일 §5의 칸) / 한정 표시 — HEX와 각 색이 이 주제의 무엇에서 왔는지
- 서체: 한 가족. 크기 Hero / 제목 / 핵심 문장 / 본문 / 캡션
- 레이아웃: 설명 장 제목의 위치·크기(모두 동일) · 좌우 여백 · 캡션 위치(왼쪽 아래)
- Character Model: 이름 · 식별 요소 3~5개 한 줄 · 틀리기 쉬운 요소: 하나 · 외형 근거(자산 ID / 05 근거 ID / 없음) — 캐릭터·인물 그림이 없으면 "없음"
- (유형 파일 §5의 추가 칸 — 예: 화풍·모티프, 또는 그래프·표 스타일)
- 피할 것: 이 주제에서 피할 분위기와 범용 PPT 패턴

## Deck Rhythm
장마다 Beat · 주인공(또는 패턴) — 쓰는 법은 유형 파일 §5

## 자산
A01 · 내용 · 출처 · 상태 · 쓰는 장 (없으면 "검증된 자산 없음")

---

## Slide 1 — <Beat>
### 화면
- 주인공: 무엇을 · 화면의 몇 % · 어디에 (유형 파일 §5대로)
- 구성: 제목·문구·주인공의 위치 (유형 파일 §5대로)
- 캐릭터: 등장하면 Character Model 문장을 **그대로** (요약·참조 금지)
- 화풍 · 강조: 유형 파일 §5가 요구하는 장에만
### 제목
- 첫 줄
- 둘째 줄
### 화면 문구
- 한 줄 = 한 항목
### 출처
유형 파일 §4의 형식 한 줄 또는 "없음"
### 한정
없음
### 최종 편집
공식 이미지로 교체할 자리 (자산 ID·위치) 또는 "없음"
### 발표자 메모
(06의 발표자 메모 + 앞뒤 장 연결)
### 근거
S01, S03

(Slide마다 반복. 비는 필드는 "없음")

# 제작 지시
(§4 블록 + 유형 파일 §8의 줄 그대로 — 도구가 프롬프트로 넣는다)
```

## 4. 제작 지시 블록 — 그대로 옮기고, 끝에 유형 파일 §8의 줄을 잇는다

```text
슬라이드마다 「화면」이 정한 주인공이 가장 먼저 보이게 두세요. 넓은 여백에 작은 글자나 작은 요소 하나만 두지 마세요.
덱 전체를 Art Direction의 색과 서체 한 가족으로 통일하세요. 제목이 있는 장은 제목을 모두 같은 크기, 같은 위치에 두세요.
안내선·격자를 그리지 마세요. 세로쓰기 금지. 글자가 화면 밖으로 넘치면 크기를 줄이세요.
「제목」과 「화면 문구」의 항목 하나가 화면의 한 줄입니다. 그 위치에서만 줄을 바꾸고, 문구를 바꾸거나 합치지 마세요.
「제목」이 "없음"인 장에는 제목을 만들지 마세요. 같은 문장을 제목과 캡션에 두 번 쓰지 마세요.
「출처」가 있는 장에는 그 줄을 글자 그대로 왼쪽 아래 작은 한 줄로 반드시 쓰세요. "없음"인 장에는 쓰지 마세요.
「한정」은 관련 숫자나 인용 바로 옆에 한 줄로 두세요.
「발표자 메모」「근거」「최종 편집」「Deck Rhythm」「자산」은 화면에 표시하지 말고 슬라이드로 만들지도 마세요.
관계·순서·수치는 도식·연표·큰 숫자로 보여 주세요.
캐릭터가 나오면 「화면」의 묘사대로, 모든 장에서 같은 모습으로 그리세요. 외형 근거가 "없음"인 캐릭터는 얼굴·머리색 없는 완전한 검은 실루엣이나 소품으로만 그리세요. 「강조」의 외형은 꼭 지키세요.
로고, "공식" 표기, 실존 인물의 사진풍 얼굴은 만들지 마세요. Slide Title 같은 자리표시자를 남기지 마세요.
업로드된 자료에 없는 사실·수치·인용을 추가하거나 계산하지 마세요. 슬라이드 순서와 메시지를 바꾸지 마세요.
```

## 5. 제출 전 점검
발표규격 §6과 유형 파일 §7의 재작업 대상을 장마다 대조한다. 더해서: 장 수가 06과 같은가 · Character Model(유형이 요구하면 화풍)이
**글자 그대로**인가 · 출처가 06의 「출처 표시: 예」 장에만 있는가 · 유형 파일 §5의 「화면」 요구를 채웠는가.

전문을 마지막 응답 본문으로 반환한다.
