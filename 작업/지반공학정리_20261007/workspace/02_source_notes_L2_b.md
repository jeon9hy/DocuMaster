# L2 In-situ Test (51p) — 교안 직독 노트 후반부 (쪽=PDF쪽, 슬라이드 하단 번호와 같음)
- p28~30 **VST 예제 12.9**: 정규압밀 점토, 지표 아래 10 m 지점, LL=60, PL=25, w=30%, Gs=2.68, 지층: 건조모래 3 m(γ=15.5 kN/m³) + 점토 7 m(지하수위 3 m 아래). 구하는 것: 일축압축강도 qu.
  - Skempton: Cu(VST)/σ'0 = 0.11 + 0.0037·PI
  - e = wGs = 0.3×2.68 = 0.8 (포화) → γ'clay = (Gs−1)/(1+e)·γw = 1.68×9.81/1.8 = 9.16 kN/m³
  - σ'0 = 3×15.5 + 7×9.16 = 110.62 kPa
  - PI = 60−25 = 35 → Cu(VST) = 110.62×(0.11+0.0037×35) = 26.49 kPa
  - 보정 (12.51)(12.52): λ = 1.7 − 0.54 log(PI) → Cu = λ·Cu(VST) = [1.7−0.54 log 35]×26.49 = 22.95 kPa
  - qu = 2Cu = 45.9 kPa
  - 그림 p29 오른쪽(지층 단면, 24 m 층, 10 m 지점)
- p31 PMT(공내재하시험) ASTM D4719: 사전 굴착공에 프로브(d=73 mm, L=440 mm) 삽입, 수압으로 팽창, 원통공동팽창이론. 구하는 값 P0(lift-off 압력), E(탄성계수), τmax(전단강도), PL(한계압력). [그림 p31]
- p32 PMT 식: Es = 2(1+μs)·V0·Δp/ΔV ; Es = 2(1+μs)·Gs ; Gs = V0·Δp/ΔV ; Ko = p0/σ'o. 곡선: Zone I 재재하, Zone II 의사탄성, Zone III 소성 [그림 p32]
- p33 DMT(평판딜라토미터): 강철 날 + 원형 막, 질소가스로 팽창. A-reading(막이 초기 위치 도달), B-reading(1.1 mm 변위). [그림 p33]
- p34 DMT 식: Marchetti(1980) p0≈A+ΔA, p1=B−ΔB. Schmertmann(1986) p0=1.05(A−zm+ΔA)−0.05(B−zm−ΔB), p1=B−zm−ΔB (zm=게이지 영점).
  - 재료지수 ID=(p1−p0)/(p0−u0) ; 딜라토미터 계수 ED=34.7(p1−p0) ; 수평응력지수 KD=(p0−u0)/σ'v0
  - γT=1.12 γw (ED/σatm)^0.1 (ID)^−0.05
- p35 DMT 깊이별 프로파일(Po,P1 / ID / ED / KD) [그림]
- p36 ED–ID 흙분류도 + ID표: <0.1 연약 점성토·유기질토; 0.1~0.35 점성토; 0.35~0.6 실트질 점토; 0.6~0.9 점토질 실트; 0.9~1.2 모래질 실트; 1.2~1.8 실트질 모래; >3.3 모래 [그림 p36 크롭 후보]
- p37~40 탄성파: P파(압축파, 입자운동=진행방향 평행), S파(전단파, 수직), Rayleigh(R파, 타원/후진 회전), Love(L파, 수평 횡운동)
- p41 Crosshole(ASTM D4428): 두 시추공 사이 Vs = Δx/Δt [그림]
- p42 Downhole: R1²=z1²+x², R2²=z2²+x², Vs = ΔR/Δt [그림]
- p43~44 Suspension logging(PS logging): 공내 sonde, 한 시추공만 필요, downhole 결과와 Vs 비교
- p45 SASW: 표면파 분산곡선(dispersion curve) → 역해석(inversion) → Vs 프로파일. 가진원과 수진기 2개 [그림]
- p46~47 MASW(능동, 다채널) / Ambient noise(AAM, 수동, 상시미동)
- p48~49 Vs 프로파일 예: BH-230, BH-188, VS30(150~378 m/s) — 지층 F 매립, C 점토, WS 풍화토, WR 풍화암, SR 연암, R 암
- p50 N–Vs 경험식: Vs=65.64N^0.407 (Sun 2013), Vs=144.7N^0.380 (정남훈·이종규 2009), Vs=98.38N^0.29 (김동수 2003). Brandenberg(2010), Kwak(2015)은 회귀식 표만
- p51 시추주상도(Boring log) 읽기: 지하수위, 심도, 지층 설명, SPT N값, 시료 종류
