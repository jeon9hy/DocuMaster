# L1 Shear Strength of Soils (38p) — 교안 직독 노트 (쪽=PDF쪽; 슬라이드 하단 번호와 중반부터 1~2 어긋남)
개요: A 응력상태·응력경로·변형·파괴(MC) / B 실험(직접전단·삼축) / C 사질·점토 강도 → 이 PDF는 A만 담음(38쪽, p38까지 마찰각표)
- p4~5 응력텐서 3×3, 주응력 σ1 최대/σ2 중간/σ3 최소 [그림 p5 크롭]
- p6~8 2D: σv, σh, 부호규약 "수직응력 + = 압축, 전단응력 + = 시계방향"(p7·p10·p11). 연직응력 Δσv 증가 → Mohr 원 커짐(p8, 그림)
- p9 예제(문제 틀): ① σ1=σ3=10kPa 등방(원=점, τmax=0) ② 연직 70kPa로 증가 → 원 그리고 최대 편차응력·최대 전단응력 [σh=10 σv=70 → 편차 60, τmax=30]
- p10 σv>σh: Mohr 원에서 σv 점이 위(τ1 +), σh 점 아래(−τ1), 두 점을 잇는 직경 [그림]
- p11~13 예제 2: σv=70, σh=10, τ=40 kPa(수직·수평 경계에 전단 40). 문제: 최대전단응력, 최대전단면, 주응력 σ1·σ3, 주응력면. 해: 중심 C=(40,0), R=50 → σ1=90, σ3=−10kPa; 그림에 각 36.9°·53.1°(원 중심각). p13(PDF p14 시트) "수평에서 반시계 10° 면의 응력" → 원에서 20° 회전: σ=54.51? 표기: σh,10=25.49, σv,10=54.51, |τ10|=47.85 kPa; 원 중심(40,0) R=50 [그림 sheets/L1_013-014, 015-016(그림 큼)]
- p14 극점법(Pole): ①기준면 선택 ②기준면에 평행선 ③극점 ④관심면에 평행선 ⑤응력 계산 [그림 Fig10.5 Cengage]
- p15~17 전응력 vs 유효응력: σ'n=σn−u, τ'=τ ; 흙의 강도는 유효응력과 관계. 텐서 σ'=σ−u(대각), 전단 불변
- p18 응력경로: p,p',q 는 전응력/유효 모두 가능. ESP(유효응력경로) TSP(전응력경로). σ1 증가·σ3 일정 → 45° 직선(q–p)
- p20 Lambe 좌표: p'=(σ1'+σ3')/2, q=(σ1'−σ3')/2; 파괴선 Kf선과 α, φ': (Mohr 원 꼭대기 점들) [그림]
- p21 변형: εz=Δh/h, γ=Δl/h. p22 변형텐서·주변형률
- p23~24 탄성: 등방 선형탄성 행렬(1/E, −μ/E, 1/G); G=E/[2(1+ν)], K=E/[3(1−2ν)]
- p25~26 평균응력·편차응력: Δσm=(Δσ1+Δσ2+Δσ3)/3 (3D), 2D Δσm=(Δσ1+Δσ3)/2; 토질에서 편차응력 Δσdev=Δσ1−Δσ3 (p26 오른쪽 박스)
- p27~28 평균변형률 εm=εv/3, εv=Δε1+Δε2+Δε3=Δεx+Δεy+Δεz; K=Δσm/εv=Δσm/(3εm)
- p29 강도 정의(응력-변형률 곡선: strength=peak, stiffness=초기기울기; 극한한계상태 vs 사용한계상태)
- p30 흙의 강도 = 전단강도(내부 저항의 최대) / p31 편차응력 σd=σ1−σ3 (삼축 모식 + 곡선)
- p32 전단강도 영향요인 5: 흙 성질(간극비·입자특성), 현재 응력상태, 응력이력(OCR), 파괴까지의 응력경로, 배수조건. "마찰 + 입자 맞물림(interlocking)"
- p33 Mohr 가설 τf=f(σ'f) ; p34 마찰: T=μN, μ=tanφ', τf=σ'f tanφ' [그림 slip plane]
- p35 MC: τf=c+σ' tanφ' (조립토 c=0 원점 통과, 세립토 c 절편) [그림]
- p36 용어: τf 전단강도, c 점착력(입자 시멘트 힘), φ' 유효마찰각, Su 비배수전단강도(정체적 전단)
- p37(시트 037-038) 마찰각 표 φ'peak / φ'cs: 자갈 35–50/30–35; 조립+세립 혼합 30–40/28–33; 모래 32–50/27–37; 실트·실트질모래 27–35/24–32; 점토 20–30/15–30 (장석 많은 모래 높은 값, 석영 모래 낮은 값)
