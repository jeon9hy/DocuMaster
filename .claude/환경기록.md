# 환경기록 — 이 PC의 실측 색인

한 항목 = 한 줄(증상 → 대응). 관찰만 적고 추정은 "추정"이라고 쓴다. 사건 경위는 `작업/<ID>/기록.md`에 둔다.
옛 원문은 `archive/환경기록_원문_20260919.md`에 있다 — 한 줄로 부족할 때만 그 번호를 grep한다. 찾기: `grep -n "E-025" .claude/환경기록.md`

## 환경 (2026-09-19)
Windows 11 Pro · PowerShell 5.1 + Git Bash · Python 3.12 · PyMuPDF 1.28 · python-pptx 1.0.2 · Pillow 12.3 · Edge(HTML→PDF) · Pretendard 설치 ·
Office16(PowerPoint COM 가능) · pandoc·weasyprint·LibreOffice 없음 · Codex CLI `codex.cmd` 0.154.0 ·
nlm 0.11.4 `~/.local/bin/nlm.exe` — 로그인 계정은 바뀔 수 있으니 매번 `check`로 확인

## 도구·환경
- **E-001** PDF 변환기가 없다 → `md2html.py` + Edge 헤드리스 인쇄 + PyMuPDF 쪽번호·검사
- **E-002** Edge는 종료 뒤 몇 초 지나 PDF를 쓴다 → `make_pdf.py`의 mtime 대기(최대 40초)를 빼지 않는다
- **E-003** PyMuPDF 기본 폰트는 한글을 "..."로 그린다(텍스트 추출은 정상) → 텍스트 추출은 시각 확인을 대신하지 않는다
- **E-004** 기계 검사는 표 잘림·쪽 나눔·폰트 폴백을 못 잡는다 → 해당 쪽을 PNG로 본다
- **E-005** Git Bash에서 python 한글 출력이 깨진다 → `PYTHONIOENCODING=utf-8`. 파일은 멀쩡하다
- **E-006** 커스텀 `subagent_type`은 인식되지 않는다 → `general-purpose` + 역할 파일 삽입. CLAUDE.md는 서브에이전트에 자동으로 실린다
- **E-007** `codex exec resume`은 원 세션의 폴더·샌드박스를 잇는다(`-C`·`-s` 없음). `--last`는 엉뚱한 세션을 에러 없이 잇는다 → ID로만
- **E-008** Codex가 셸로 한글 파일명을 읽으면 깨진다 → 파일별 자체 읽기. workspace 파일명은 ASCII
- **E-009** PowerShell에서 `codex`가 실행 정책에 막힌다 → `codex.cmd`. 웹 검색은 `-c tools.web_search=true`
- **E-010** Codex 백그라운드 실행에 파이프를 걸면 로그가 0바이트다
- **E-011** opus 서브에이전트 429 → 새로 띄우지 말고 리셋 뒤 `SendMessage`로 재개
- **E-012** python에 넘기는 절대경로는 `C:/...` (`/c/...`는 실패)
- **E-013** Codex 사용량 한도는 계정 단위다(모델을 바꿔도 같은 리셋 시각, E-034) → 기다리거나 사용자에게. 검증 도중 막히면 사용자 승인 뒤 대행(E-033)
- **E-014** nlm은 CLI로 쓴다(MCP 미등록). 파일 업로드 43종 가능. 비공식 API라 깨지면 수동 경로로
- **E-015** `nlm ... create`는 생성을 시작만 한다 → `studio status` 폴링. 전체 지시는 노트북 페르소나로 건다. 00~05(06) 업로드는 도구가 막는다
- **E-016** `nlm download`: report·mind-map·data-table에는 `--no-progress`가 없다 · 대상 파일이 있으면 실패 → 파이프라인이 처리한다
- **E-017** NotebookLM 슬라이드는 장마다 통 이미지다(텍스트 0자) → 숫자 검사 불가, 눈으로 본다. 수정은 `nlm slides revise`. 표지 +1장은 정상. 오른쪽 아래는 워터마크
- **E-018** 슬라이드 생성 약 8분. NotebookLM은 팩에 없는 계산값(83% 등)을 더한다 → 「팩에 없는 숫자」 검사

- **E-028** 폴링이 완성된 슬라이드를 `unknown`으로 본다 → 10분 넘으면 `download slide-deck` 직접 시도

- **E-037** `nlm slides create` RESOURCE_EXHAUSTED(하루 생성 한도로 추정) → 몇 번 두드리지 말고 멈춘다. 파이프라인에는 생성 재시도가 없다
- **E-038** NotebookLM 불가 시 pptxgenjs 대체(사용자 지시 때만): `npm install pptxgenjs`, PowerPoint COM으로 PDF를 뽑아 QA. 이미지 비중 목표 미달을 먼저 알린다

- **E-039** 2026-09-19 개편: 요르=Codex·유리=sonnet, PPT에서 아냐 제외, 06은 새 세션, DOC 퇴고 1회
- **E-040** 2026-09-19 압축: 파일 크기 예산(CLAUDE.md §9), 모드별 규격·비주얼 절차 분리, 역할+절차 통합

- **E-046** 렘 v03(사용자 평: 최고): NotebookLM은 **반복해 적은 것은 지키고 한 번 적은 것은 사전 지식으로 되돌아간다** — 화풍 흔들림·클로즈업 앞머리 이탈·"실루엣이나 뒷모습"에 뒷머리 → 스토리 화풍 장마다 반복, 틀리기 쉬운 요소 + `- 강조:`, 근거 없는 인물은 완전한 검은 실루엣. Render Gate: 공식 외형과 맞는 추가 세부는 통과
- **검증 완료(스토리)** 글자 자리·분할 금지·줄 한도·출처 필수·수치 설명 줄·Character Model 반복 — 렘 v03

  `page-break-inside: avoid` 여백. **쪽수는 조판으로 못 줄인다** — 01에서 분량을 잡을 때 (본문 글자 + 출처 건수)로 먼저 검산한다
